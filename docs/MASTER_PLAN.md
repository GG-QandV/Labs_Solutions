# AI Automation Lab — MASTER PLAN

## 1. Контекст и позиционирование

**Проект:** AI Automation Lab — витрина живых AI-автоматизаций с лендингом, демо RAG/OCR/агентов и API для пользовательских агентов.

**Модель:** большинство технических компонентов — open-source и/или self-hosted; платящий продукт — анализ процесса, архитектура, внедрение, интеграции, сопровождение, а не продажа «токенов» или закрытого SaaS.

**Рынок фокуса на старте:** ЕС/ЕЭЗ + глобальные клиенты, которые готовы работать с EU-юрлицом и прозрачной моделью внедрения.

## 2. Технологический стек

### 2.1. Фронтенд и лендинг

- Astro + Tailwind CSS — статический лендинг и контентные страницы (SEO/GEO, высокая скорость, минимальная серверная нагрузка).
- React (внутри Astro как islands) — интерактивные демо (загрузка документов, чат, таблицы, формочки).
- TypeScript — единый язык для фронтенда и части backend-логики.

### 2.2. Backend и демо-сервисы

- FastAPI (Python) или Node.js/Fastify — API Gateway для демо и внутренних инструментов.
- RAG-слой: Qdrant (или Weaviate) как основное векторное хранилище, обёрнутое REST/GRPC, с фильтрацией по метаданным.
- Embeddings: ONNX/TEI-совместимая модель в Docker (мультиязычная, достаточно быстрая для онлайн-демо).
- Reranking: лёгкий cross-encoder в Docker для повышения качества выдачи.
- NER: GLiNER/другая INT8 NER-модель в Docker для извлечения сущностей/полей.
- OCR: PaddleOCR в Docker (на втором этапе) — извлечение текста из сканов, сохранение в PostgreSQL.

### 2.3. Хранилища данных

- PostgreSQL — структуры: пользователи, сессии, демо-документы (текст), истории запросов, метаданные.
- MinIO (или другой S3-совместимый сторедж) — бинарные оригиналы документов (PDF, изображения, docx).
- Qdrant — векторы чанков + словари метаданных.

### 2.4. Инфраструктура и деплой

- VPS (Hetzner/Netcup/аналог) — Docker + Coolify для оркестрации сервисов.
- Cloudflare Pages — хостинг лендинга/контентных страниц (CDN, SSL, бесплатные билды и статический трафик). [web:93]
- Cloudflare Workers / Pages Functions — тонкий gateway-слой: аутентификация, rate limit, прокси к API на VPS, Stripe webhook, минимальная валидация.

### 2.5. Платежи и биллинг

- Stripe Checkout + Invoice — приём предоплат за этапы внедрения, резервирование времени, постоплата по демо/результатам.
- Внутренняя модель: оплата поэтапно (аудит, архитектура, MVP-внедрение, развитие).

## 3. Архитектура (укрупнённо)

```text
Пользователь / агент
        │
Cloudflare Pages: лендинг, кейсы, документация
        │
Cloudflare Worker: gateway, авторизация, лимиты, Stripe webhook
        │
VPS (Coolify + Docker)
 ├── api-gateway (FastAPI)
 ├── chat-orchestrator
 ├── rag-api
 ├── ocr-worker (этап 2)
 ├── background-worker (очереди)
 ├── postgres
 ├── qdrant
 ├── minio
 ├── redis
 ├── embeddings-service
 ├── reranker-service
 ├── ner-service
 └── monitoring + логирование
        │
Внешние API: LLM-провайдеры, OCR SaaS при необходимости, CRM/email/Telegram/ERP клиентов
```

**Принцип:** публичный контур (демо и лендинг) изолирован от клиентских окружений; при внедрении реальных процессов инфраструктура ставится либо в контуре клиента (его сервер/VPS/cloud), либо на отдельном выделенном сервере с чёткими юридическими и техническими границами.

## 4. Деплой и окружения

### 4.1. Контуры

- `marketing.example.com` → Cloudflare Pages (Astro-лендинг, документация, блог/кейсы).
- `api.example.com` → Cloudflare Worker → VPS API Gateway.
- `demo.example.com` → Astro/React UI, ходящий к demo API.
- `ops.example.com` → закрытая админка: статистика демо, заявки, управление тарифами, журнал действий.

## 5. Roadmap реализации (оценочные сроки)

Исходим из того, что основную работу на старте делает один full-stack/ML инженер с опытом, параллельно вы готовите контент и маркетинг.

### Этап 0 — Discovery и архитектурный скелет (3–5 дней)

- Финализация позиционирования (услуги, демо, формат оффера).
- Выбор юрисдикции (см. раздел 8), исходного стека и хостинга.
- Макет лендинга и структуры страниц.
- Решение по тому, какие демо делаем рабочими на первом релизе.

### Этап 1 — Лендинг и контент (5–8 дней)

- Astro-проект, Tailwind дизайн-система.
- Страницы: главная, /solutions/*, /how-we-work, /architecture, /open-source-and-licenses.
- Форма заявки и интеграция с вашей CRM/почтой.

### Этап 2 — Lead flow и Stripe (2–4 дня)

- Сценарий: заявка → короткий созвон → согласованный scope → Stripe Invoice/Checkout.
- Stripe webhook и обновление статуса лида/проекта.

### Этап 3 — RAG demo (7–12 дней)

- Загружаемый документ → MinIO → извлечение текста → PostgreSQL → chunking → Qdrant → ответ LLM с цитатами.
- Ограничения демо (размер файла, число запросов, TTL сессий, автоудаление).

### Этап 4 — LLM-чат как каталог решений (3–5 дней)

- Чат, который отвечает только по заранее заданным материалам: ваши услуги, архитектуры, FAQ.
- Интеграция CTA: «Запустить демо», «Запросить аудит», «Подключить агента по API».

### Этап 5 — API агентов (5–8 дней)

- REST/OpenAPI слой: `/v1/catalog`, `/v1/demo/sessions`, `/v1/rag/query`, `/v1/workflows/run`, `/v1/leads`.
- API keys, scopes, лимиты, базовый audit log.

### Этап 6 — OCR и интеграционные workflows (7–15 дней)

- Очередь для OCR (PaddleOCR), сохранение распознанного текста и полей в PostgreSQL.
- 2–3 демонстрационных рабочих сценария: обработка входящих документов, сверка счетов, генерация отчёта.

**Реалистичный первый публичный релиз:** 4–6 недель (этапы 0–5). Этап 6 — запуск после первых лидов/клиентов.

## 6. Финансовый прогноз: старт инфраструктуры и токены

### 6.1. Инфраструктура (первый год, ориентировочно)

Оценки берутся по типовым тарифам европейских VPS и Cloudflare.

| Статья | Оценка / месяц | Комментарий |
|---|---:|---|
| Домен + DNS | 1–2 € | Годовая оплата домена с разбивкой по месяцам |
| Cloudflare Pages / DNS | 0 € | Статический хостинг и базовый CDN в free tier. [web:93] |
| VPS (Hetzner/аналог, 4–8 GB RAM) | 10–30 € | Один сервер под все Docker-сервисы демо |
| Backup-хранилище | 3–10 € | Дополнительное S3/объектное хранилище либо удвоенные диски |
| Email/SMTP/почтовый сервис | 0–15 € | В зависимости от выбранного провайдера |
| Monitoring/логирование | 0–10 € | Можно начать с open-source, платные решения позже |

**Итого без LLM/OCR:** ориентировочно **14–67 €/мес.** — зависит от выбранного VPS и желаемого уровня резервирования.

### 6.2. LLM и токены (demo-бюджет)

LLM-расходы зависят от выбранных моделей. Многие гайды по ценам показывают, что дешёвые модели уровня Claude Haiku/GPT-4.1 Mini стоят порядка **≈1–2 USD за 1M input tokens и 5–6 USD за 1M output tokens**; точные ставки нужно проверять по текущей документации провайдера на момент запуска. [web:134]

Бюджет демо:

- На старт — **20–75 USD в месяц** на LLM+embeddings.
- Жёсткий лимит по количеству демо-сессий, длине документов и числу запросов.
- Мониторинг: считать input/output tokens по каждому endpoint и отключать бесплатное демо при приближении к лимиту.

Формула для грубой оценки:

\( cost = \frac{tokens_{in}}{1{,}000{,}000} * rate_{in} + \frac{tokens_{out}}{1{,}000{,}000} * rate_{out} \) [web:134]

### 6.3. Что важно

- Инфраструктура дешёвая; реальный «сжигатель денег» — токены и OCR.
- Надо жёстко ограничивать публичный демо-контур и отслеживать usage.
- При появлении платящих клиентов LLM-расходы лучше переносить на их API-ключи/контракты либо закладывать в тариф.

## 7. Маркетинговое позиционирование

### 7.1. Ключевая идея

> Я не продаю «магический ИИ», я показываю реальные автоматизации на ваших процессах и внедряю переносимые open-source решения под ваши данные и сервисы.

Основные акценты:

- Живые демо на лендинге — пользователь сразу видит, как выглядит автоматизация.
- Большинство компонентов — open-source с понятными лицензиями; вы платите за архитектуру, интеграцию и результат.
- Данные, документы, ключи и доступы при внедрении остаются у клиента.
- Всё, что критично для денег/юридики, работает с human-in-the-loop.

### 7.2. Страницы и месседжи

- Главная: «AI-автоматизация, которая встроена в процессы, а не в маркетинг».
- Solutions: по типам задач (документы, заявки, email/CRM, офис, агенты).
- How we work: этапы — аудит, архитектура, MVP, расширение.
- Architecture: блок-схемы, стек, переносимость, безопасность.
- Open source & licenses: список основных проектов и лицензий.
- API for agents: как ваши агенты могут подключаться и использовать платформу.

CTA: не «купить ИИ», а

- «Показать свой процесс»;
- «Запросить архитектуру MVP»;
- «Забронировать слот на аудит».

## 8. Юридический статус и юрисдикции

Ниже — краткий анализ трёх основных вариантов, о которых мы говорили: Эстония, Болгария и Wyoming.

### 8.1. Эстония OÜ (e-Residency)

Факты:

- e-Residency позволяет нерезиденту зарегистрировать OÜ полностью онлайн, с цифровой подписью. [web:208][web:217]
- Налоговая модель: 0 % на нераспределённую прибыль, 22 % CIT при распределении (22/78 от дивиденда). [web:152]
- Эстония — юрлицо ЕС/ЕЭЗ, нормально воспринимается банками и финтехами.

Плюсы:

- Цифровой UX регистрации и администрирования.
- Хороший бренд среди IT/стартап-среды.
- Поддержка от Revolut Business / Wise Business как компании ЕЭЗ. [web:219][web:222]

Минусы:

- Вопрос о налоговой резиденции личной (Испания/Украина) и постоянном представительстве надо решать с локальным консультантом.

### 8.2. Болгария OOD/EOOD

Факты:

- Плоский корпоративный налог 10 % — самая низкая ставка CIT в ЕС. [web:201][web:199]
- Минимальный уставной капитал 2 BGN ≈ 1 €. [web:192]
- Компания — юрлицо ЕС, формально подходит под Revolut/Wise как EEA-entity. [web:219][web:222]

Плюсы:

- Минимальная ставка CIT и символический капитал.
- Еврозона и доступ к рынку ЕС.

Минусы:

- Менее цифровое администрирование, чем в Эстонии.
- Сложнее открыть банковский счёт нерезиденту без локального сопровождения. [web:192][web:214]

### 8.3. Wyoming LLC (США)

Факты:

- Регистрация удалённо, без требований к гражданству; filing fee 100 $, registered agent ~125–200 $/год. [web:244][web:206][web:213]
- Нет подоходного налога штата и франшизы; при отсутствии US trade or business федеральный налог США часто равен 0. [web:244][web:238][web:248]
- Для foreign-owned single-member LLC ежегодно обязателен Form 5472 + pro forma 1120, штраф за пропуск — минимум 25 000 $/год. [web:249][web:256][web:261][web:260]

Для резидентов Испании/Украины:

- Испания: CFC/TFI (Art. 91 LIRPF) и worldwide income — AEAT видит прибыль LLC и атрибутирует её вам; плюс отчётность по зарубежным активам (Modelo 720). [web:251][web:255][web:257]
- Украина: правила КИК — LLC почти автоматически становится контролируемой иностранной компанией, требуются уведомление, отчёт и налог с прибыли КИК; штрафы за неподачу значительны. [web:240][web:242][web:243]

Вывод: Wyoming LLC полезна как инструмент для US-биллинга и платёжной инфраструктуры, но **не даёт налогового нуля** для резидентов Испании/Украины при соблюдении их НК.

## 9. Правовые аспекты: лицензии, оплаты, юридика

### 9.1. Лицензии open-source

Для каждого компонента нужно фиксировать:

- Название проекта и версию.
- Лицензию (Apache-2.0, MIT, GPL/AGPL, коммерческую и т.п.).
- Обязательства: указание авторства, copyleft (GPL/AGPL), ограничения по SaaS/хостингу.

Особое внимание:

- GPL/AGPL: могут создавать обязательства по раскрытию модификаций при предоставлении сервиса через сеть.
- Модели с ограничительными лицензиями (например, только некоммерческое использование) нельзя использовать в коммерческом сервисе без отдельной договорной базы.

### 9.2. Приём оплат

- Stripe: только через официальные Checkout/Invoice/Customer Portal, без хранения данных карты у вас. [web:69]
- Юридические документы:
  - Договор оказания услуг (MSA) + приложения с описанием этапов и объёма работ.
  - Политика возвратов и отмен.
  - Политика коммерческой тайны и работы с конфиденциальными документами.

### 9.3. Документы по данным и безопасности

Нужно подготовить минимум:

- Privacy Policy (под GDPR/местные законы).
- Terms of Use / Terms of Service.
- Data Processing Agreement (DPA) — для клиентов, передающих вам данные.
- Security Policy — базовый описательный документ по доступам, логированию, резервному копированию.
- Политика по демо-данным: что именно происходит с документами и запросами, загрузженными в демо (TTL, автудаление, неиспользование для обучения).

- Ограничения и безопасность.
