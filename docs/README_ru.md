# Labs Solutions

AI-автоматизации и лендинг-решения для бизнеса.

Демонстрация рабочих AI-автоматизаций на реальных сценариях — извлечение данных, проверка, бизнес-правила, подтверждение человеком и экспорт в CRM, email, PDF, задачи и отчёты.

## Содержание

- `docs/` — спецификации, промпты, архитектурный анализ, гайды деплоя
- `backend/` — распакованные модули демо (opshub, rag-demo, pdf-demo, stt-mvp)

## Демо-модули

| Модуль               | Описание                                                                                     |
| -------------------- | -------------------------------------------------------------------------------------------- |
| **Landing Labs**     | B2B лендинг для AI automation lab — i18n (EN/UK/PL/RU), темы, статика HTML/CSS/JS, пререндер |
| **OpsHub**           | Операционный хаб для оркестрации парка демо                                                  |
| **RAG Demo**         | Демо RAG — запросы к документам через AI                                                     |
| **PDF Report**       | Автоматизированная генерация PDF-отчётов                                                     |
| **STT-LLM**          | Распознавание речи + обработка LLM                                                           |
| **Speech Translate** | Локальная транскрибация whisper.cpp + облачный перевод (спецификация MVP)                    |

## Стек

- **Лендинг:** Чистый HTML/CSS/JS, ноль зависимостей, nginx статика
- **Бэкенд:** Python, FastAPI-контракты
- **AI:** whisper.cpp, ONNX, LLM API (DeepSeek, opencode)
- **Инфраструктура:** Netcup VPS, Docker, Traefik, systemd
