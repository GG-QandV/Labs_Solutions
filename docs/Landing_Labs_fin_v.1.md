## Landing_Labs_fin_v.1

**Ограничения выполнения (важное — читать до кода):**

1. **Требование «все тексты, включая подзаголовки, грузятся отдельно» выполнено частично и намеренно.** Полностью динамическая подгрузка текста ломает индексацию: краулер должен видеть текст в HTML. Решение: `index.html` — английский текст в разметке, `uk/index.html` собирается скриптом `build/prerender.py`, а `i18n/en.json` + `i18n/uk.json` работают для мгновенного переключения в браузере. Все тексты вынесены в словари — править их можно только там.
2. Шрифты не приложены (нужно скачать и просабсетить — инструкция в `DEPLOY.md §5`). Без них работает системный fallback, вёрстка не ломается.
3. Бэкенд не написан — отдан контракт эндпоинтов, а не код.
4. Turnstile — только слот в разметке; ключей нет.

## Ключевые решения

| Пункт        | Решение                                                                                                                                             |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Email        | `contact@labs.mnemostroma.com` (нейтральный, подходит и для КП, и для биржи). Альтернативы: `build@` — активнее, `hello@` — слишком casual для B2B  |
| Стек         | Чистый HTML/CSS/JS, ноль зависимостей — статика в nginx 64 MB, отдельно от API, падение бэкенда не роняет сайт                                      |
| Бренд        | В шапке `LABS` крупно + `mnemostroma` мелким моно — Labs первым, как вы просили                                                                     |
| Шрифты       | Archivo (заголовки) + Inter (текст) + JetBrains Mono (данные), self-hosted variable woff2                                                           |
| Сигнатура    | Карточка прогона в hero, которая **демонстративно останавливается** на «Awaiting approval» — единственная анимация на странице                      |
| Безопасность | CSP без `unsafe-inline` (тема вынесена в `theme-init.js`), honeypot, rate-limit, хэш IP вместо сырого, фронт **никогда** не ходит в OpsHub напрямую |

Проверено: HTML валиден в обеих версиях, JS и Python компилируются, все **197 ключей i18n** сходятся между разметкой, `en.json` и `uk.json` — расхождений нет.
