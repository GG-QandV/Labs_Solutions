# Labs Mnemostroma — лендинг живых демо (v0.2.1)

Статический фронт для `labs.mnemostroma.com`: витрина работающих AI-автоматизаций,
доказательство квалификации для клиентов с бирж и посадочная для трафика из других источников.

## Состав пакета

```
index.html                  главная (английская версия, текст зашит в разметке — SEO)
uk/index.html               украинская версия, генерируется скриптом
pl/index.html               польская версия
ru/index.html               русская версия
assets/css/style.css        дизайн-система, обе темы, адаптив
assets/js/theme-init.js     синхронная установка темы и языка (без вспышки)
assets/js/app.js            i18n, тема, меню, анимация pipeline, формы, статусы демо
assets/fonts/               ПУСТО — положить woff2 (см. docs/DEPLOY.md §5)
assets/icons/               ПУСТО — сюда SVG из локальной коллекции
i18n/en.json, i18n/uk.json, i18n/pl.json, i18n/ru.json  все тексты, включая подзаголовки
robots.txt, sitemap.xml, site.webmanifest
build/prerender.py          сборка /uk/, /pl/, /ru/ из index.html + i18n/*.json
docs/BACKEND_API.md         контракт эндпоинтов для разработчика бэкенда
docs/DEPLOY.md              деплой на Netcup VPS, Traefik, CSP, шрифты, SEO-чеклист
docs/ICONS.md               замена плейсхолдеров, список из 31 иконки
```

## Быстрый старт

```bash
python3 build/prerender.py
python3 -m http.server 8080     # открыть http://localhost:8080
```

Без бэкенда форма вернёт ошибку сети, карточки демо останутся в состоянии «soon» — это штатное поведение.

## Дизайн-система

| Токен | Тёмная | Светлая |
|:--|:--|:--|
| фон | `#14101E` глубокий фиолет | `#E8EDF4` серо-голубой |
| поверхность | `#211A33` | `#FFFFFF` |
| текст | `#EFEAF8` | `#1B1A28` |
| акцент | `#F3B78D` пастельный оранжевый | `#7E5490` сливовый средней глубины |
| граница | `#3A2F55` | `#C9D3E2` |

Шрифты: **Archivo** (заголовки, ось ширины использована в логотипе и h1), **Inter** (текст),
**JetBrains Mono** (состояния, поля, подписи). Всё self-hosted.

Тема: `prefers-color-scheme` → сохранённый выбор в `localStorage` перекрывает системный.
Язык: браузерный `uk/ru/be` → украинский, `pl` → польский, `ru` → русский, иначе английский; выбор пользователя сохраняется.

## Сигнатурный элемент

Правая карточка в hero — прогон конвейера, который **демонстративно останавливается** на шаге
«Awaiting approval» и ждёт нажатия. Это единственная анимация на странице и главный тезис оффера:
модель готовит, отправляет человек. При `prefers-reduced-motion` карточка сразу показывает состояние gate.

## Известные ограничения этой версии

1. **i18n и SEO — компромисс.** Требование «все тексты грузятся отдельно» выполнено словарями `i18n/*.json`,
   но текст, отданный краулеру, обязан быть в HTML. Поэтому английская версия зашита в `index.html`,
   украинская собирается `prerender.py`, а JSON используется для мгновенного переключения в браузере.
   Полностью динамическая загрузка текста уронила бы индексацию — это осознанный отход от буквальной формулировки.
2. Форма отправляет данные, но **бэкенда в пакете нет** — контракт описан в `docs/BACKEND_API.md`.
3. Turnstile не подключён: в разметке только слот. До подключения работают honeypot и серверный rate-limit.
4. Шрифты не приложены (лицензии OFL позволяют, но файлы нужно скачать и просабсетить — инструкция в DEPLOY.md).
5. Страницы демо, `/privacy`, `/terms`, страница API — не входят в v0.2.1, ссылки на них помечены как TODO.
6. Аналитика не подключена намеренно: любой сторонний скрипт придётся вносить в CSP.
