# Сюда положить готовые бинарники

Собранные локально, под архитектуру хоста (обычно x86_64 Linux):

| Файл | Обязателен | Что это |
|---|---|---|
| `gatewayd` | да | шлюз ACP-A2A (`cargo build --release` в ACP-A2A_gateway) |
| `hermes` | нужен хотя бы один агент | ACP-агент, запускается как `hermes acp` |
| `claurst` | нет | второй ACP-агент другой реализации |

`install.sh` перед копированием проверяет архитектуру и линковку (`ldd`) — если бинарь
собран под другую ОС/glibc, установка остановится с понятной ошибкой, а не сломается потом.

Права: `chmod +x bin/*` перед запуском установки.

Файлы в этом каталоге не коммитятся (см. `.gitignore`).
