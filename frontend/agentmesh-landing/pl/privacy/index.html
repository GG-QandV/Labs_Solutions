Co zbieramy

This site is served without third-party tracking scripts. We collect standard server logs (IP address, user agent, requested paths) for operational and security purposes.

Sesje demo

When you run the live sandbox check, a short-lived session is created with temporary credentials and synthetic test data. The session expires automatically within 30 minutes and can be revoked at any time from the compatibility report.

Czego nigdy nie przechowujemy

  • Permanent access tokens or credentials
  • Raw conversation payloads
  • Internal hostnames or gateway addresses
